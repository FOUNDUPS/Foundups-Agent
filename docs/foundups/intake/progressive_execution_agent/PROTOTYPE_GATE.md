# Progressive Execution Agent - Prototype Gate

## POC -> Prototype Criteria
- [ ] Community-discovery loop executes end-to-end from graph gap to evidence receipt to next-best-action.
- [ ] Evidence provenance is preserved and distinguishes agent inference from evidence-backed/external verification states.
- [ ] Operator can complete the PoC without manually selecting a SKILLz or downstream project phase.
- [ ] WRE/WSP 95 boundary is preserved; no duplicate runtime skill engine is introduced.
- [ ] Project-specific facts are separated from reusable SKILLz instructions.
- [ ] At least one out-of-sequence opportunity can be captured without breaking the project model.
- [ ] The same community-discovery capability can be parameterized for a second locality/project context without rewriting the core procedure.

## Prototype Scope Expansion
Add multiple dependency domains and capability families: municipal/site-control discovery, academic demand, enterprise demand, grid feasibility, and document/evidence verification. Introduce audience-specific project projections and richer scheduling/deadline arbitration while retaining one-next-action progressive disclosure for the founder.

## Risk Gates
- [ ] Privacy validated
- [ ] Security reviewed
- [ ] Compliance checked (if applicable)
- [ ] Consent and recording rules validated for field interviews
- [ ] Legal/technical authority boundaries reviewed
- [ ] Evidence retention and deletion policy defined
