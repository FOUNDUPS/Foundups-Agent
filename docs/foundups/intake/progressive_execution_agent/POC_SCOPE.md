# Progressive Execution Agent - POC Scope

## Minimum Viable POC
Prove one complete evidence-driven execution loop using community feasibility as the field domain: the DAE identifies a missing community-evidence requirement, presents one interview task to the founder, invokes the appropriate community-discovery capability/SKILLz, captures structured evidence, updates project state, and generates the next-best action from the new evidence.

## Included in POC
- One FoundUp project context using Fukui E-Singularity as the proving environment.
- A minimal dependency graph containing community-feasibility evidence requirements.
- A minimal evidence ledger with provenance and verification state.
- One progressive mobile task surface: current objective, one micro-task, required proof.
- Community discovery interview workflow with Japanese/English contextual dialogue support.
- Capture of audio/text evidence with consent metadata.
- Structured extraction of claims, objections/conditions, stakeholder referrals, and evidence references.
- Capability request/hook compatible with WRE/WSP 95 boundaries.
- Re-evaluation of project state after evidence commit.
- Next-best-action output.

## Explicitly Excluded from POC
- Full municipal, utility, academic, enterprise, environmental, grant, or incorporation workflows.
- Creation of a parallel SKILLz registry or execution engine.
- Autonomous legal conclusions or binding commitments.
- Production tokenomics, CABR rewards, DAO activation, or marketplace integration.
- Full public stakeholder QR portal.
- Guaranteed anti-copy/anti-screenshot controls.
- Complete PWA production deployment.

## Success Criteria
Given a known community-evidence gap, a novice operator can complete one guided field interview and the system can produce a traceable evidence receipt, update the ledger/graph, and select a materially justified next action without the operator manually selecting the workflow capability.

## Trust Wedge
The operator receives immediate free value: a guided interview, structured meeting record, extracted objections/referrals, and a clear next action instead of having to understand or manage the entire project plan.
