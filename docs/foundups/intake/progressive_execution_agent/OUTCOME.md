# Progressive Execution Agent - Outcome Definition

## User Outcome
A founder with limited domain expertise can execute a complex real-world FoundUp safely and progressively because the DAE carries the project model, evidence, dependencies, stakeholder context, and procedural knowledge while exposing only the smallest useful next action.

## Success Metrics
- A novice founder can complete a real field-discovery workflow without manually choosing tools, SKILLz, or downstream project phases.
- Every completed action produces traceable evidence that updates project state and influences the next-best-action decision.
- The DAE can adapt when reality arrives out of sequence without forcing the operator through a rigid phase pipeline.
- Reusable capability SKILLz can be applied across different FoundUps and geographies without embedding project-specific facts in the SKILLz themselves.
- The same execution substrate can move from one PoC project to another without redesigning the workflow engine.

## Anti-Outcomes (What This Is NOT)
- Not a linear checklist engine that assumes complex projects unfold in a fixed order.
- Not a replacement for WRE or WSP 95 SKILLz governance.
- Not an autonomous authority that converts AI inference into legal, technical, financial, or community truth without evidence.
- Not an E-Singularity-specific application.
- Not a monolithic prompt containing all project knowledge and procedures.
