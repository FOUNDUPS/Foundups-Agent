# FoundUp pitch package

Read and follow the module-owned
[FoundUp pitch package Skillz](../../../modules/platform_integration/social_media_orchestrator/skillz/foundup_pitch_package/SKILLz.md).
That file is the canonical instruction; this entry makes it discoverable to Codex.

Use it to turn an idea into finished pitch narration and a companion deck without
requiring the person to write marketing copy. Create local draft artifacts in the
requested output directory. Scope is creative drafting and available rendering;
resident RedDog automation and public/chain effects have separate admission.
Keep the existing OUTCOME -> SOLUTION -> PAIN structure: vision; PoC -> Prototype
-> MVP delivery path; obstacles to reaching and implementing the Solution.
Supporting why/what/how/CTA stay within it.
