# LinkedIn strategic outreach

Read the [master routing contract](../../docs/LINKEDIN_ACTIVITY_ROUTING.md).
Handle inbound obligations first during full runs. Select contacts from actual
relevance to AI, regional compute, research, education, infrastructure or PPP,
not nationality or fame. Historic target names are leads, not an approved batch.
Resolve identity, profile/company context and full prior conversation before
drafting. Recent connection/subscription alone is not blanket marketing consent.

Ask one concrete question or provide genuinely new evidence. Avoid generic
checking-in, repeated links, fabricated familiarity and promises of financing or
partnership. Use the recipient's established language. Identify 0102, keep the
project/domain name intact and link only when helpful. Never exploit private
profile data to influence political views.

Show the bounded recipient batch and exact drafts for approval, preserving prior
authorization for unchanged drafts. Execute through inbox with immediate history
recheck, send-once verification and private receipts. Silence is not a trigger
for repeated follow-ups. Return sent, held, awaiting reply and decision-needed.
