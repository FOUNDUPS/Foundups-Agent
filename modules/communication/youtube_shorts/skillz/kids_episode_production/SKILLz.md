## Produce an episode

1. Choose one measurable learning objective, a safe action, language and age band. Default the initial draft to English, ages 3–6, exactly 15 seconds; label these assumptions and preserve subsequent corrections.
2. Write a short original script: introduce → demonstrate → invite action → affirm. Allow time for the child to respond. Use original recurring characters. Treat the reference image as visual direction, not footage or character assets.
3. Prepare original or licensed video and music. For Suno, use official exports and record track ID, creation/download dates, subscription/rights evidence and remix status. Read current provider terms before commercial publishing. Do not treat a third-party Suno API as official.
4. For Google generation, verify current official Lyria/Veo documentation, model access and budget before a paid call. Use existing video generation owners. Do not claim a configured subscription implies API access. Record the provider/model, request, cost if known, and resulting asset provenance without secrets.
5. Assemble 15 seconds in the existing local editor. Source-video audio is discarded; music starts at zero, so prepare a trimmed music file to choose a later segment. Use draft/final resolution presets; maintain the same educational and review standard in both. Import audio, set caption cues and render MP4 plus SRT.
6. Listen to actual audio and inspect the actual rendered video. Verify caption timing, pronunciation, objective accuracy, activity safety, continuity, duration, framing and sound levels. Generated script timestamps are provisional; manually correct or use a verified alignment service. Never claim word-level karaoke alignment from sentence cues.
7. Have a reviewer independent of the author evaluate the output. Preserve failures and revisions. Only prepare publishing after rights and review evidence exist. Require an explicitly selected, observed authorized channel, made-for-kids declaration, appropriate separate synthetic-media disclosure, and a private/unlisted first upload through the existing publisher. Do not call legacy public-default upload helpers.
8. Report separately: local implementation/tests, rendered asset review, provider calls, upload, deployment and recurring-worker state. Do not report planned features as operational.
