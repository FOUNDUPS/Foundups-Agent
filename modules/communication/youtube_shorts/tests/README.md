# YouTube Shorts offline boundary tests

Run only a specifically qualified selection. Live demos in this directory are
operational programs and must not be collected by a blanket pytest invocation.

`test_operator_upload_policy.py` uses fake media/service/generation collaborators,
actual private queue claims and complete production class definitions. It requires
no Google/model SDK. `test_youtube_publisher_boundary.py` remains the adjacent
publisher contract regression. No test result proves actual provider generation,
public upload, installed account access or independent published-video readback.
