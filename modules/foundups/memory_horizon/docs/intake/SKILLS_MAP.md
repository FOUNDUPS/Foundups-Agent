# Memory Horizon - Skills Map

## Required capability lanes

| Lane | Capability | POC need |
|---|---|---|
| Behavioral experiment | timing, randomized trials, response capture | High |
| Game UX | branching state, simple narrative/events | High |
| Measurement | event/probe linkage, contamination control | High |
| Statistics | descriptive retention curve, uncertainty | Medium |
| Mobile web | Safari/Chrome/PWA behavior | High |
| Privacy | local-first data and explicit export | High |
| Clinical research | instrument comparison, protocol design | Advisory only |
| Regulatory | medical-device boundary | Deferred until claims justify |

## Reuse candidates

- jsPsych for browser behavioral-experiment timelines/data capture.
- Existing FoundUps web/PWA conventions after owner inspection.
- Existing repository chart/export utilities if compatible.
- No new orchestration system.

## Do not conflate

- working memory with episodic retention
- reaction time with memory accuracy
- recognition with free recall
- game skill with cognitive recovery
- a descriptive curve with diagnosis
