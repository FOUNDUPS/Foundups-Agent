# Memory Horizon - Intake Source

## Origin

Intake initiated by 012 on 2026-09-20 after observing short-interval memory failures following a family member's sports-related head injury and researching post-traumatic amnesia, concussion assessment and digital cognitive testing.

The motivating observation informs the product question but is not research evidence and is not stored here as identifiable patient data.

## Product question

Can a very simple browser game continuously generate unique episodic events and probe them after adaptive delays, producing an auditable retention curve while minimizing rehearsal and repeated-test contamination?

## Intake decisions

- Stable internal ID: `memory_horizon`.
- Working display name: Memory Horizon.
- Browser-first.
- Research/measurement only.
- POC local/private by default.
- No diagnosis or clinical threshold.
- Future host proposal only: `memory.foundups.com`.
