# Memory Horizon - Prototype Gate

## POC -> Prototype

- [ ] POC acceptance in POC_SCOPE passes.
- [ ] Timing integrity tested under background/foreground, sleep and network changes.
- [ ] Probe contamination audit confirms retired-event rule.
- [ ] At least three alternate event/form pools exist.
- [ ] Scoring/data dictionary versioned.
- [ ] Accessibility review covers text size, motor input and color dependence.
- [ ] Privacy threat model completed.
- [ ] Independent reviewer can reconstruct results from raw export.

## Prototype additions

- Multiple sessions and longitudinal comparison.
- Counterbalanced/alternate forms.
- Research study configuration.
- Optional study IDs without direct identity.
- Configurable delay schedules.
- More event classes and language packs.
- Dashboard separating raw observations from derived estimates.
- Optional import of externally administered instrument scores for research correlation, never as hidden labels used to tune on the same sample.

## Research gate

Before claims about concussion/TBI, dementia, stroke or another medical condition:
- [ ] Prospective protocol.
- [ ] Appropriate ethics/IRB review.
- [ ] Defined population and exclusion criteria.
- [ ] Reference instrument/clinical outcome specified prospectively.
- [ ] Sample-size/power plan.
- [ ] Practice-effect and device-effect analysis.
- [ ] Blinded analysis where feasible.
- [ ] Missing-data/attrition plan.
- [ ] External replication target.

## Prototype -> research MVP

- [ ] Reliability and completion burden acceptable for intended study design.
- [ ] Export/data deletion controls tested.
- [ ] Security review complete for any cloud mode.
- [ ] No medical-device marketing language without applicable review.
- [ ] Published methodology distinguishes descriptive retention curves from validated clinical interpretation.
