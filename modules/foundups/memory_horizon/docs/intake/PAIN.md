# Memory Horizon - Pain Definition

## Primary pain

Acute and longitudinal memory change is difficult for families, coaches and even patients to describe precisely. Observations often remain anecdotal: "he forgot something from a few minutes ago." Existing clinical tools are structured snapshots, while many consumer brain games optimize engagement or generic scores rather than an auditable event-to-delay retention curve.

## Specific pains

- Naturalistic memory failures are clinically/research-relevant but poorly timestamped.
- Repeatedly asking the same question contaminates the memory being measured.
- General cognitive scores mix memory with attention, speed and other functions.
- Fixed tests suffer practice effects during frequent repeated measurement.
- Caregiver observations and formal test data are usually separated.
- Browser accessibility and low-friction repeated measurement remain inconsistent.
- Medical claims can outrun validation if product boundaries are not explicit.

## Existing alternatives

- A-WPTAS: validated acute post-traumatic-amnesia instrument; clinician-oriented and not a game.
- SCAT6: multidomain sports-concussion assessment with memory components.
- NIH Toolbox: validated episodic/learning assessments.
- TestMyBrain: browser/mobile cognitive tests with alternate forms and longitudinal/high-frequency designs.
- MemTrax: browser continuous-recognition memory test.
- Consumer brain games: broad engagement/cognition focus.

The product hypothesis is not "memory tests do not exist." It is that an adaptive, event-grounded, game-native retention timeline with contamination controls may fill a useful research niche.

## Evidence gap

No evidence yet establishes that Memory Horizon predicts clinical outcome, identifies concussion, measures post-traumatic amnesia equivalently to A-WPTAS, or improves care. Those are future research questions.
