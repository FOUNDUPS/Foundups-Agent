# Japan Hyperscaler Report 001

**2026年9月 / eSingularity.ai**

## 日本は「次の印西」を全国につくろうとしているのか

### 結論

日本のデータセンター政策は、単なる施設誘致から、**大規模データセンター集積地を国土政策として計画する段階**に入っている。

経済産業省は「データセンター集積型GX戦略地域」を制度化し、既存の東京・大阪圏への集中だけに依存せず、地方に新しい大規模集積拠点を形成する方針を明示している。選定要件には、将来的な**GW級への拡張可能性**、半径10km圏内で合計30ha以上を目安とする産業用地、通信冗長性、電力余力、水、交通、災害リスク、自治体のコミット、そして地域との共生が含まれる。

これは、単独のデータセンターではなく、複数施設・送電・変電・通信を一体化した**ハイパースケール・クラスター**を地方に計画的につくる政策と読める。

## 1. 国の政策シグナル

METIの公募要領は、データセンター集積型GX戦略地域について、既存集積地以外の地方に新たな大規模集積を形成し、電力系統を先行的・計画的に整備しながら関連産業クラスターまで形成することを期待している。

また、GX戦略地域の検討資料では、将来的に10年程度でGW級の供給が可能なことを例示し、30ha以上の産業用地、電力・通信・水・交通・災害耐性、地域共生などを評価項目としている。

**JHR判定:** 高重要度。これは日本のデータセンター配置を変える国家レベルの政策転換である。

## 2. 千葉県印西市は先行事例

印西市は日本を代表するデータセンター集積地になっているが、その成長は地域計画との摩擦も生んでいる。

2025年、印西市は駅周辺や生活圏に隣接するデータセンター等の建設について、市民から「より市民目線のまちづくり」を求める意見が出ているとして、市独自の新たなルールづくりを検討すると公表した。

2026年には、市長がデータセンターを社会に必要な産業であり税収やデジタル教育の面で重要なパートナーと評価する一方、地域との共存には**ゾーニング**と事業者の地域貢献が重要だと説明している。住民による訴訟や署名活動も市の会見で言及されている。

**JHR判定:** 印西は「成功例」だけではない。ハイパースケール成長が土地利用、景観、生活圏、地権者、住民合意にどう影響するかを示す、日本で最も重要な観察地点の一つである。

## 3. eSingularity / COG DCへの意味

重要なのは「データセンターが必要かどうか」ではない。AI時代には計算資源の需要増加がほぼ避けられない。

問題は、**どの配置モデルを選ぶか**である。

### モデルA: ハイパースケール集積

- 100MW〜GW級へ拡張可能な巨大キャンパス
- 大規模な土地集約
- 新設・増強される送電・変電設備
- 大手事業者による集中運営
- 地域税収や投資効果が期待できる一方、土地利用と住民合意への負荷が大きい

### モデルB: COG DC / 地域分散型

- 1MW〜20MW程度の比較的小規模な拠点を複数地域へ配置
- 既存建物や地域資産の再利用を優先
- 再生可能電力や地域電源との接続
- 排熱を温泉、給湯、暖房、融雪、農業へ利用
- 学校、大学、病院、自治体、地域企業が近隣計算資源を使える可能性

日本政府の地方分散政策が、結果として「地方に複数の新しい印西をつくる」だけになるのか。それとも、さらに細かく分散した地域所有・地域利用型インフラも組み合わせるのか。これがJHRが継続して検証する中心仮説である。

## 4. Fukui Signal

福井が現時点でデータセンター集積型GX戦略地域の中心候補として前面に出ていないことは、必ずしも不利ではない。

むしろ、大規模な土地取得・電力予約・投機的開発が本格化する前に、福井独自の分散型モデルを設計できる余地がある。

福井には、脱炭素電源、既存建築物、地域熱利用、大学・教育、製造業、人口減少地域の再生という複数の課題が重なる。これらを別々に処理するのではなく、**地域計算インフラを公共的な産業基盤として先に設計する**ことが、eSingularityの検証テーマになる。

## 5. JHRが今後追跡するもの

- 47都道府県のDC政策・誘致・規制
- GX戦略地域の選定と具体的な候補地
- 系統接続、変電所、送電線の増強
- ハイパースケール事業者の新規キャンパス
- 農地・森林・寺社・集落周辺の土地転換
- 地権者・農家・住民・自治会の反応
- 市町村のゾーニング、条例、景観規制
- 電力、水、騒音、排熱、税収、雇用の実績
- 米国のハイパースケール集中との比較
- 福井で先回りできる政策機会
