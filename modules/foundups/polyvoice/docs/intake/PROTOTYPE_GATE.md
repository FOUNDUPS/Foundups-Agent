# Poly Voice — prototype gate

All gates are unpassed until independently evidenced:

- Qualified local capture/speech and review on the actual device, including interruption and failure.
- Private-content non-egress across normal, error, logging, telemetry and update paths.
- Reviewed encryption/key, retention/deletion/hold and recovery design; explicit OS-backup limitations.
- Reviewed commitment scheme, minimal receipt transport, replay/revision and evidence labels.
- Current-office attribution/delegation only where independently established; never inferred from phone or biometric possession.
- Jurisdiction, institution, confidentiality, records and security review before real meetings.
- Defined support owner and correction procedure; no automatic public export or guilt scoring.

[Roadmap](../../ROADMAP.md) owns progression. A documentation merge does not pass these gates.
