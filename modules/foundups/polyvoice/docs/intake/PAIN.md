# Poly Voice — pain and barriers

Hypothesis: participants need accountability without turning complete private meetings into centrally stored media. Public receipt interpretation, consent, personal/business classification and voluntary disclosure create trust burdens.

Implementation barriers include local speech support/accuracy, device interruption, memory/battery/storage limits, encryption/key recovery, receipt linkability, incomplete records, lawful retention/deletion and source-to-summary verification. Existing camera/vision or host speech tests do not establish this workflow.

These are hypotheses and engineering gates, not allegations about any office or proof that non-use is suspicious. [PoC scope](POC_SCOPE.md) limits the first test.
