# Kids Episodes — Prototype gate

Status: pending. Do not promote from a fixture-only encoder test.

## PoC to prototype
- [ ] Real 15-second episode reviewed for one correct learning goal and safe activity.
- [ ] Both aspect ratios and draft/final exports measured and visually checked.
- [ ] Actual audio/caption synchronization verified.
- [ ] Asset provenance and permitted use recorded.
- [ ] Adult creator can edit, preview, export and reopen an episode reliably.
- [ ] Failure/cancellation paths preserve work and report useful errors.

## Story-product gate
- [ ] Story input produces an ordered, editable sequence with stable IDs and coherent learning progression.
- [ ] Character/story continuity is verified across linked episodes.
- [ ] Generation retries/checkpoints avoid duplicate outputs or repeated charges.
- [ ] Renderer-only capabilities are distinguished from autonomous generation in the UI/status.
- [ ] Future EDUIT activity/game links resolve to verified capabilities before display.

## Expanded prototype
Verified generation adapters, reusable character/lesson templates, bounded trend worker and review queue.

## Runtime/publication gates
- [ ] Provider account, permission and cost limits verified.
- [ ] Trend evidence, quotas and scheduling admission verified.
- [ ] Intended YouTube channel pinned; made-for-kids metadata explicit.
- [ ] Independent educational/rights review recorded before publication.
- [ ] pfMALL auth, tenant and discovery contracts validated before hosting/listing.
