# Contributing to EDUIT

Use the parent repository’s contribution, security, WSP and review rules. Start with
[README.md](README.md), [ROADMAP.md](ROADMAP.md), and the [source register](docs/SOURCE_REGISTER.md).
The first build packet is EDUIT_POC_PLAY_LOOP_PHASE1, not a mandate to build every layer.

Source claims require a specific locator. Mark new proposals as proposals. Do not copy
unpublished manuscripts, personal correspondence, family details or credentials into Git.
Use synthetic fixtures only. New runtime dependencies require owner review and a pinned
build strategy. Inspect the nearest existing tests and update TestModLog before adding
coverage; reuse existing registry and README validators rather than duplicating them.

Submit one coherent change per PR. Include scope, exact source base, tests run/not run,
privacy/learning consequences, rollback, and remaining blockers. Respect required checks
and review gates; never fabricate WSP/runtime receipts or promote maturity labels to
make a check pass. Contributions do not authorize outreach, data collection, token sales,
partner appointments, domain changes, or product claims.
