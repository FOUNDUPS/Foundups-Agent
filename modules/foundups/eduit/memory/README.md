# EDUIT memory boundary

Store source locators, versioned architecture decisions, non-identifying test evidence,
release records and aggregate operational lessons here only when actually produced.
Canonical history belongs in docs/HISTORY.md; change history belongs in ModLog.md.
Do not duplicate those documents as a second authority.

Never store identifiable learner events, guardian contacts, biometrics, private source
manuscripts, secrets, unapproved ability profiles or provider credentials in repository
memory. Future operational stores must be tenant/purpose scoped and separately governed.
A previous session’s statement is not current runtime evidence; check the owning source.
