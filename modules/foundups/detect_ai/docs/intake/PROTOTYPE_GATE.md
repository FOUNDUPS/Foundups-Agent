# Can You Detect AI? - Prototype Gate

## POC -> Prototype Criteria
- [ ] Complete source-bound duplicate, catalog, entitlement and dependency checks.
- [ ] Pass all round-state, authorization, truth-isolation, scoring and disconnect tests.
- [ ] Complete the consenting pilot defined in POC_SCOPE and retain auditable aggregate evidence.
- [ ] Independently review client payloads for identity/model leakage.
- [ ] Record model license/provider permission, configuration and measured cost.
- [ ] Confirm moderation coverage, retention controls and reproducible deployment rollback.

## Prototype Scope Expansion
Add an approved hosted baseline and multiple small open configurations only through one versioned adapter contract. Add registered agent judges, without giving them hidden labels or privileged metadata. Separate live-interaction judging from transcript judging. Add authenticated rankings, reason labels, opt-in evaluation export, abuse/rate limits and repeatable benchmark cohorts. Discord integration remains optional.

Proposed ranked-human eligibility: 50 qualified rounds including at least 20 per assignment class; otherwise show provisional status. This is a product threshold, not a statistical power claim. Agent rankings require a versioned configuration, disclosed operator and at least the same class coverage. Benchmark publication requires a prospectively specified sample/power plan, participant/round clustering, attrition reporting and uncertainty; do not treat a small leaderboard as a definitive model ranking.

## Risk Gates
- [ ] Privacy validated: participation, evaluation, training and publication are separate decisions; both human participants must permit any transcript reuse involving them.
- [ ] Security reviewed: server-only truth and secrets, session authorization, content escaping, replay/idempotency controls and safe model isolation.
- [ ] Compliance checked: age/geography, anonymous-chat operation, provider policies, data rights and any later reward mechanics.
- [ ] Incentives reviewed: anti-collusion, duplicate accounts, bot-assisted human play, reward budget and appeals.
- [ ] Red Dog evaluation reviewed independently of imitation score.

## Prototype -> MVP Criteria
- [ ] Public matchmaking has measured human supply; no undisclosed AI substitution.
- [ ] Scores recompute from authoritative events; incidents and corrections are auditable.
- [ ] Separate human-detector, agent-detector and conversational-model boards show conditions, sample sizes and uncertainty.
- [ ] Costs, p95 latency, abuse rate and moderation response meet a prospectively approved operating budget and service target.
- [ ] Retention/deletion jobs and consent withdrawal paths work in production-like tests.
- [ ] Held-out Red Dog evaluation establishes whether any reuse helps; no benchmark/training overlap.
- [ ] Public methodology distinguishes verified assignment from unprovable human authorship.
- [ ] Economic reward integration, when activated, has explicit authority, funding, independent verification, idempotency, dispute handling and applicable review. Until then token status remains TOKEN_DEFERRED.

No runtime, registration, publication, token or payout gate passes merely because these documents exist.
