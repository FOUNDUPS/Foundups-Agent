# HPC prototype gate

- [ ] Verify the public PoC on its approved host and preserve mobile regression evidence.
- [ ] Qualify rights, moderation, duplicate handling, corrections, consent and retention for submissions.
- [ ] Agree on the shared seven-level preference contract, keyboard/touch equivalence, edit/clear and anti-abuse tests.
- [ ] Review the Voice interface and confirm that any handoff forwards only approved context.

The prototype extends discovery with nominations and review. Privacy, security and applicable policy review are required before persistence or external actions.
