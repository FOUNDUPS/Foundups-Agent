# Private plate contract

The deployed prototype expects seven reviewed image plates named:

`frame-01.png` through `frame-07.png`.

The public monorepo intentionally does not contain those generated portraits. The private deployment repository supplies them. Every plate must use the same dimensions, background composition, lighting, body placement, and crop. Only the intended head angle, gaze, and restrained expression may change.

The private deployment also copies the canonical dog-only FoundUps mark from `public/logo-dog.png` to `red-dog.png`; do not create a second logo variant.
