# The Huang Affair | 黄乐

Status: **prototype FoundUp; private seven-state PWA under review**.

*The Huang Affair* is a fictionalized limited-series concept about love, access, and compute. Public presentation must separate sourced chronology, open questions, and dramatized narrative. It must not present private motives, relationships, covert conduct, or causation as established facts.

## Current prototype

Sprint 1 proves one interaction only:

- one locked cinematic environment;
- seven full-frame background states;
- only the two head angles and gazes change between frames;
- a live center aperture updates with the selected chapter;
- swipe, numbered buttons, arrows, and keyboard navigation;
- mobile-first layout with a responsive desktop composition;
- explicit `documented / questioned / dramatized` labels.

The image plates remain in the private deployment repository. The public monorepo contains the implementation contract and source shell, not private research masters or unpublished generated portrait assets.

## Seven chapters

1. The Selection
2. The School
3. University Burning
4. The Credential

7. The Affair

These are working story containers, not factual findings.
